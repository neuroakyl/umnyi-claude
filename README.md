# Умный Claude

Апгрейд Claude Code одной фразой. После установки Claude работает как у нас: знает, кто ты, держит порядок в папках,
сам запоминает твои правки, не задаёт лишних вопросов, проверяет свою работу и обновляется сам.

Что внутри:
- **Паспорт** — Claude знает, кто ты и как с тобой говорить (заполняется по интервью).
- **Правила работы** — просто, по делу, «готово» только с доказательством, ключи и деньги под защитой.
- **Память** — сказал «так не делай» один раз, больше не повторит.
- **Навыки** — проверка системы, свой навык из любого дела, новый проект, передача дел между чатами, проверка чужих навыков, GitHub,
  база о себе (интервью голосом, разбор материалов, расшифровка кыргызской речи) и брендбук.
- **Помощники** — критик, проверка фактов, рабочий для механики.
- **Автономный режим** — Claude не встаёт на каждом шаге, спрашивает только про деньги, выкладку и удаление.
- **Цифровой мозг** — папка `Projects`, где лежит всё о тебе и твоих проектах.
- **Автообновление** — новые версии ставятся сами, Claude скажет, что нового.

## Установка (Windows и Mac)
1. Поставь приложение Claude (claude.com/download), войди, открой вкладку **Code**, выбери любую папку.
2. Напиши: **«Установи Умный Claude: https://github.com/neuroakyl/umnyi-claude»**
3. Делай только то, о чём попросит Claude: нажать «Разрешить» или «Установить», перезапустить приложение.
4. В конце открой новый чат в папке `Projects` и спроси: **«всё работает?»**

### Для Claude Code: как установить
Пользователь — новичок. Всё делай сам, говори просто, одно действие за раз, на его языке.
Скачай пакет и выполни `УСТАНОВКА.md` из него по шагам:
- Mac и Windows (Git Bash): `git clone https://github.com/neuroakyl/umnyi-claude "$HOME/.claude/umnyi"` (папка есть — `git -C "$HOME/.claude/umnyi" pull`).
- Нет git: Windows — `winget install --id Git.Git -e --source winget --accept-source-agreements --accept-package-agreements`,
  потом попроси перезапустить приложение Claude и написать «продолжай установку»; Mac — `xcode-select --install`
  («появится окно, нажми „Установить“, подожди 5–10 минут»), дождись, пока `xcode-select -p` вернёт путь.

## Безопасность
В пакете только инструкции и код, ни ключей, ни личных данных. Ключи живут у тебя в `~/.claude/.env`, Claude их не читает.
Твой паспорт, мозг и свои правила обновление не трогает. Лицензия — MIT.
