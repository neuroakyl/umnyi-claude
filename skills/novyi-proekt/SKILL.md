# Новый проект

1. Уточни одной-двумя фразами: что это, зачем, что будет результатом. Не ясно — до 3 вопросов.
2. Контент (ролики, посты, план) — это не новый проект, а `~/Projects/завод/`. Всё остальное — `~/Projects/проекты/<имя>/`
   (имя по-русски или латиницей, без пробелов: `лендинг`, `wildberries`, `crm-таблица`).
3. Создай `README.md` проекта: **Что это · Зачем · Статус · Следующий шаг**. Пустых подпапок «на будущее» не создавай.
4. Допиши строку в таблицу `~/Projects/CLAUDE.md` и первую задачу в `~/Projects/Задачи.md`.
5. Если в папке будет код — сохрани начальную версию в Git (`git init`, первый коммит): это кнопка «отменить».
6. Дальше по правилу «большая задача»: короткий план, потом работа.
