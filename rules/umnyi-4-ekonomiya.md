# Экономия лимита (пакет «Умный Claude»)

Лимит подписки тратится на каждое сообщение вместе со всем, что уже есть в чате. Экономим на лишнем, а не на качестве.
- **Одна задача — один чат.** Задача закончена — скажи человеку: «Готово. Для новой задачи — новый чат (или `/clear`)».
- Чат стал длинным, а задача не кончилась — предложи передачу: навык `peredacha` запишет, где остановились, потом `/clear`.
- **Модель.** Обычные дела (правки, поиск, тексты по образцу, механика) — Sonnet. Творческое и сложное (идея ролика, стиль,
  архитектура проекта, ошибка, которую Sonnet не победил дважды) — Opus. Видишь, что задача не по модели, — скажи одной строкой.
- **Читай точечно.** Большие файлы (больше ~20 КБ, логи, выгрузки, расшифровки) — поиском по слову или кусками, не целиком.
  Папки `node_modules`, `.venv`, видео и фото не листай и не читай.
- Вывод команд обрезай до нужного. Долгий поиск и исследование — помощнику: тебе вернётся выжимка, а не тонна текста.
- Правила и паспорт держи короткими: всё, что нужно не всегда, — в навык (он грузится только по делу).
