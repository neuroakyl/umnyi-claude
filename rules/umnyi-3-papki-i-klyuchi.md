# Папки, ключи, деньги (пакет «Умный Claude»)

## Где что лежит
```
~/Projects/              цифровой мозг человека; Claude Code открывается отсюда
  CLAUDE.md              карта проектов        Задачи.md   все задачи
  мозг/                  всё о человеке: кто-я, аудитория, продукт, голос, бренд (брендбук) …
  материалы/входящие/    что он дал о себе (видео, голосовые, документы); расшифровки — материалы/расшифровки/
  завод/                 контент-завод: local.md (настройки), планы/, ролики/ГГГГ-ММ-ДД-тема/, креатив/, медиатека/
  проекты/<имя>/         любое другое дело; у каждого README.md: что, зачем, статус, следующий шаг
~/.claude/               CLAUDE.md (паспорт), .env (все ключи), rules/, skills/, agents/, umnyi/ (этот пакет)
```
- Новый проект — новая папка в `проекты/` с `README.md`. Пустых папок «на будущее» не создавай.
- Файлы, которые человек прислал или скачал, **переноси** в нужную папку проекта (не копируй) и скажи куда.
- Данные человека никогда не клади в папки навыков (`~/.claude/skills/…`) и пакета (`~/.claude/umnyi/`): обновление их перезапишет.
- Временное — в системную временную папку, не в его проекты. Тяжёлое (рендеры, исходники видео) после сдачи — спроси и убери.

## Ключи
- Все ключи всех сервисов — в одном файле `~/.claude/.env`, строкой `ИМЯ=ключ`. Других мест для ключей нет.
- Ключ в чат не проси и не выводи. Нужен новый ключ — открой файл человеку (Windows: `notepad "$USERPROFILE\.claude\.env"`,
  Mac: `open -e ~/.claude/.env`), скажи, на какой сайт зайти и после какого слова вставить, «сохрани и закрой».
- Читать `.env` тебе запрещено настройками — так и надо. Скрипты берут ключ сами: переменная окружения → `~/.claude/.env`.
- Ключ прислали в чат по ошибке — скажи человеку, что его лучше заменить на сайте сервиса.
- `.env` никогда не попадает в Git, на GitHub и в облако.

## Деньги и необратимое
- Платная генерация (картинки, видео, озвучка, аватар) — сначала цена простыми словами, запуск только после «да» в этом чате.
- Покупки, подписки и оплату делает человек сам. Пароли и данные карты не вводишь никогда.
- Выложить в соцсети, отправить сообщение людям, опубликовать репозиторий — только после его «да».
- Перед большой переделкой сохрани рабочую версию (коммит в Git), чтобы можно было вернуться.
- Чужие навыки и код из интернета: сначала прочитай, что делают (куда ходят в сеть, что запускают, трогают ли ключи), лицензия
  свободная (MIT, Apache) — тогда ставь. Официальные навыки Anthropic — можно сразу.

## Windows
- Пути в коде — только через домашнюю папку (`Path.home()`, `$HOME`), никаких путей к папке пользователя, вписанных руками.
- Python на Windows запускается `py`, на Mac `python3`. Программы на Windows ставь через `winget`, на Mac — через официальный установщик.
- Не клади проекты в «Документы» и на «Рабочий стол», если их синхронизирует OneDrive: рендер ломается, облако забивается.
