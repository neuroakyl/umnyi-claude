# Установка «Умного Claude» — инструкция для Claude Code

Человек — новичок. **Всё, что можешь, делай сам.** От него — клик в системном окне, перезапуск приложения, «да».
Терминал открывать не проси. Одно действие за раз: что он увидит и куда нажать. Говори на его языке (по умолчанию русский).
`$HOME` — его домашняя папка: Mac `/Users/<имя>`, Windows `C:\Users\<имя>` (в Git Bash `/c/Users/<имя>`).

## 1. Что есть на компьютере
- Определи Windows или Mac.
- **Windows:** нужен Git for Windows (с ним у Claude появляется Bash, на нём работает пакет) и Python.
  - `git --version` не отвечает → `winget install --id Git.Git -e --source winget --accept-source-agreements --accept-package-agreements`.
    Скажи: «может появиться окно „Разрешить изменения?“ — нажми „Да“». После установки: «Закрой приложение Claude полностью и открой
    снова, напиши „продолжай установку“» — без перезапуска Claude не увидит Git Bash.
  - Python: проверь `py --version` (или `python --version`). Нет → `winget install -e --id Python.Python.3.12 --scope user`.
    `python3`, который открывает Microsoft Store, — не Python, не считай его.
  - `winget` не найден (старая Windows 10) — попроси поставить «Установщик приложений» из Microsoft Store, или скачай Git с git-scm.com.
- **Mac:** `git --version`. Нет или вылезло окно про «инструменты командной строки» → `xcode-select --install`, «нажми „Установить“,
  подожди 5–10 минут», жди, пока `xcode-select -p` вернёт путь. Вместе с Git ставится и Python 3.
- Дальше все команды — в Bash (на Windows это Git Bash внутри Claude), одинаково для обеих систем.

## 2. Скачать и поставить
1. `git clone https://github.com/neuroakyl/umnyi-claude "$HOME/.claude/umnyi"` (папка уже есть — `git -C "$HOME/.claude/umnyi" pull`).
2. `sh "$HOME/.claude/umnyi/bin/py" "$HOME/.claude/umnyi/install.py"`
   Ставит правила, навыки, помощников, паспорт-шаблон, файл ключей, папку `Projects` и вливает настройки (старые — копия
   `settings.json.umnyi-kopiya`). Чужие настройки и файлы человека не трогает. Запускать можно сколько угодно раз.
   Папку мозга можно указать другую: `--proekty "<путь>"` (не в OneDrive и не на Рабочем столе).
3. `✗` в выводе — прочитай строку и почини сам, запусти ещё раз.

## 3. Проверка
1. `sh "$HOME/.claude/umnyi/bin/py" "$HOME/.claude/umnyi/proverka.py"` — все `✓` и в конце «ВСЁ РАБОТАЕТ». `✗` — почини по строке
   «как починить» и проверь снова. `!` — подсказки, скажи их одной строкой.
2. Скажи человеку: «Готово. Теперь: 1) закрой этот чат; 2) открой новый в папке **Projects** (кнопка выбора папки → папка
   пользователя → Projects); 3) проверь, что внизу режим **Auto**; 4) напиши „всё работает?“».
3. Новый чат проверяет навык `proverka`: скрипт ещё раз + метка правил «УМНЫЙ-CLAUDE» в контексте. Это и есть «готово».
   Чего не удалось проверить — скажи прямо.

## 4. Что дальше
- Паспорт пока шаблон: заполняем по интервью (урок 3). Не заполняй сам из головы.
- GitHub — навык `github`: аккаунт, бэкап папки `Projects` в приватный репозиторий, кнопка «отменить».
- Контент-завод ставится поверх: он берёт мозг из `Projects/мозг/`, ключи из `~/.claude/.env`.
