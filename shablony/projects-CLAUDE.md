# Карта проектов

Это мой цифровой мозг. Claude Code открывать только из этой папки: тогда память одна на всё.
Кто я и как со мной работать — `~/.claude/CLAUDE.md`. Здесь только где что лежит.

| Папка | Что это | Статус |
|---|---|---|
| `мозг/` | Всё обо мне: кто я, аудитория, продукт, голос, брендбук (`бренд.md`, файлы в `бренд/`) | собираем (урок 3) |
| `материалы/` | Что я дал о себе: `входящие/` — сырьё, `расшифровки/` — тексты из аудио и видео | |
| `завод/` | Контент-завод: настройки `local.md`, `планы/`, `ролики/`, `креатив/`, `медиатека/` | ставим (урок 4) |
| `проекты/` | Всё не про контент: лендинг, магазин, таблицы | |

Все задачи — в `Задачи.md`. У каждого проекта в `проекты/` свой `README.md`: что, зачем, статус, следующий шаг.
